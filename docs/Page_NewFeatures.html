New Features

This page documents the latest features added to the Online 3D Viewer, including multiple selection, keyboard shortcuts, enhanced customization options, and improved user experience.

Multiple Selection

Overview

The Online 3D Viewer now supports multiple selection of meshes and materials, allowing users to select and work with multiple objects simultaneously.

How to Use Multiple Selection

Tree Menu Selection

  • Single Selection: Click on any mesh or material in the navigator tree
  • Multiple Selection: Hold Ctrl (Windows/Linux) or Cmd (Mac) and click multiple items
  • Visual Feedback: Selected items are highlighted with a distinct color

3D View Selection

  • Single Selection: Click on any 3D object in the viewer
  • Multiple Selection: Hold Ctrl (Windows/Linux) or Cmd (Mac) and click multiple objects
  • Real-time Highlighting: Selected objects are immediately highlighted

Multiple Selection Features

Sidebar Information

  • Combined Statistics: Shows total count, vertices, triangles, and bounding box for multiple selected meshes
  • Material Properties: Displays combined material information for multiple selected materials
  • Smart Display: Automatically switches between single and multiple selection views

Context Menu Actions

  • Hide All Selected: Right-click → "Hide all selected Meshes (H)"
  • Fit All Selected: Right-click → "Fit all selected Meshes to window"
  • Individual Actions: Single selection still works for individual operations

Keyboard Shortcuts

Selection Management

  • H - Hide selected mesh(es)
  • Shift + H - Show all meshes
  • Escape - Clear all selections

Multiple Selection

  • Ctrl + Click - Add/remove item from selection
  • Cmd + Click - Add/remove item from selection (Mac)

Enhanced Highlight Color System

Customizable Highlight Colors

The selection highlight color can now be fully customized through the settings panel.

Accessing Highlight Color Settings

  1. Click the Settings icon in the sidebar
  2. Navigate to Model Display section
  3. Find Selection Highlight Color picker

Color Picker Features

  • Real-time Updates: Color changes apply immediately as you adjust the sliders
  • Transparency Support: Full RGBA color control including alpha channel
  • Predefined Colors: 8 preset colors for quick selection
  • Persistent Settings: Your color choice is saved and restored

Default Color

  • New Default: Blue highlight color (#6496ff) with 80% opacity
  • Better Visibility: Improved contrast on both light and dark backgrounds
  • Professional Look: Modern, clean appearance

Enhanced Toolbar

Clear Selection Button

A new "Clear all selection" button has been added to the toolbar for quick access to clearing all current selections.

Toolbar Features

  • Location: After "Fit model to window" button
  • Icon: Close/X symbol for intuitive recognition
  • Tooltip: Shows "Clear all selection (Esc)" with keyboard shortcut hint
  • Functionality: Clears all selected meshes and materials

Keyboard Shortcut Integration

  • Escape Key: Same functionality as toolbar button
  • Cross-platform: Works on Windows, Mac, and Linux
  • Prevents Default: Stops browser's default Escape behavior

Improved User Experience

Visual Feedback

  • Multiple Selection Indicators: Distinct visual styling for multiple selected items
  • Real-time Updates: Immediate visual feedback for all interactions
  • Consistent Styling: Unified appearance across all selection states

Context-Aware Interface

  • Smart Context Menus: Different options based on selection state
  • Dynamic Sidebar: Content changes based on what's selected
  • Intuitive Workflow: Natural progression from single to multiple selection

Performance Optimizations

  • Efficient Selection Management: Optimized data structures for multiple selections
  • Minimal Rendering: Smart updates that only re-render when necessary
  • Memory Management: Proper cleanup of selection states

Technical Implementation

Core Components

  • MultipleSelection Class: Manages selection state with efficient data structures
  • Enhanced Navigator: Supports both single and multiple selection modes
  • Smart Sidebar: Dynamically displays relevant information
  • Real-time Color System: Immediate visual updates for color changes

Data Structures

  • Map-based Storage: Efficient lookup and comparison of selected items
  • Event-driven Updates: Reactive system that responds to user interactions
  • Persistent Settings: Cookie-based storage for user preferences

Browser Compatibility

Supported Browsers

  • Chrome: Full support for all features
  • Firefox: Full support for all features
  • Safari: Full support for all features
  • Edge: Full support for all features

Keyboard Support

  • Windows/Linux: Ctrl key for multiple selection
  • Mac: Cmd key for multiple selection
  • Cross-platform: Escape key for clearing selections

Migration Notes

For Existing Users

  • Backward Compatible: All existing functionality remains unchanged
  • Enhanced Defaults: Better default highlight color and improved UX
  • New Features: Multiple selection and keyboard shortcuts are additive

For Developers

  • API Compatibility: Existing APIs remain unchanged
  • New Methods: Additional methods available for advanced usage
  • Enhanced Events: More detailed event information for selections
