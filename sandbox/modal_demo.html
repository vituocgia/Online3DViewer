3D Viewer Modal Demo

This demo shows how to open the 3D viewer in a modal with preselected objects and receive selections back.

Features: URL encoding for special characters, postMessage for large object arrays (avoids HTTP 431 errors), and real-time selection updates.

Preselection Setup

Examples:
• Local model: assets/models/3DModel.glb
• External model: https://threejs.org/examples/models/gltf/DamagedHelmet/glTF/DamagedHelmet.gltf
• Object names: AT004138022,EFEM.001,AT004137982
• Special characters: AT004956200 %1 (will be encoded as AT004956200%20%251)
• Leave empty to use default demo model
