3D Viewer Modal Demo

This demo shows how to open the 3D viewer in a modal with preselected objects and receive selections back.

Features: URL encoding for special characters, postMessage for large object arrays (avoids HTTP 431 errors), real-time selection updates, and resizable modal.

Modal Resize: Drag the edges or corners of the modal to resize it. Use the "Reset Size" button to restore the default size and position.

Modal Control: Use the "Close" button in the top-right corner or press Escape key to close the modal. Clicking outside the modal will NOT close it.

Preselection Setup

Examples:
• Local model: assets/models/3DModel.glb
• External model: https://threejs.org/examples/models/gltf/DamagedHelmet/glTF/DamagedHelmet.gltf
• Object names: AT004138022,EFEM.001,AT004137982
• Special characters: AT004956200 %1 (will be encoded as AT004956200%20%251)
• Leave empty to use default demo model
